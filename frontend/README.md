Node.js 22.23.2 / npm 10.9.8：

```sh
cd frontend
npm ci
npm run dev
npm run lint
npm run typecheck
npm run contract:check
npm test
npm run build
```

依赖与源码均独立于 example。锁文件使用固定 Node 容器生成；T1 已建立 Node 编译 → Nginx 运行镜像，在仓库根执行 `docker build -t elect-frontend:v0.12.0 frontend`。生产入口不注册 MSW；仅显式开发配置 `VITE_ENABLE_MSW=true` 可启动场景，worker 脚本只在 Vite 开发服务器提供。详细开发、契约与测试入口见 [开发说明](../docs/开发说明.md)。
