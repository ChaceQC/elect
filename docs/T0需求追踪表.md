# T0 需求、字段、按钮与模块追踪

日期：2026-10-01；契约：0.1.0。全部 API 前缀为 `/api/v1`，完整请求/响应以 [OpenAPI](contracts/openapi.yaml)为准。

| 页面/动作 | API 能力 | 字段/异常/恢复 | 负责领域与阶段 |
| --- | --- | --- | --- |
| 打开协议、阅读、同意 | GET /auth/agreement，POST /auth/login | 版本/摘要/明确同意；阅读状态属本地，后台授权不默认勾选 | Identity，T2 |
| 验证码刷新、登录 | POST /auth/captcha，POST /auth/login | 学校图片/challenge/expires_at；失败过期重新取图，密码只在内存 | Identity/Adapter，T2 |
| 初始化/账户入口/学校重认证 | GET /auth/me，POST /auth/login | credential_version、CSRF、consent；登录已成功但 rooms loading/failed 不重提密码；账号不同 409 | Identity，T2；撤回入口 T3 |
| 退出、撤回授权 | POST /auth/logout，DELETE /auth/school-credential | 204 才确认退出；撤回用凭据版本、202 与持久操作，先监控屏障 | Identity/Monitoring，T2/T3 |
| 总览、查看其他寝室 | GET /overview，GET /room-bindings | viewing/default 分离；profile/balance/history/monitor 组件状态独立，null/stale 可见 | Gateway/Room/Monitoring，T4 |
| 已绑定列表搜索、分页、同步 | GET /room-bindings，POST /room-bindings/sync | page/total、每行可空余额、preference_version、pending_operations；ready 空才引导 | Room，T2 |
| 三级筛选与列表内搜索 | GET /room-candidates/buildings、floors、rooms；GET /room-candidates?room_id | 学校 B05–B07 的 id/label；父项改变清子项、关键词只过滤当前列表、核对精确候选 | Room/Adapter，T3 |
| 新增绑定弹窗、候选搜索/绑定 | GET /room-candidates，POST /room-bindings | candidate_id/过期/搜索质量；幂等一次逻辑请求，绑定和默认状态分开 | Room/Adapter，T3 |
| 设置默认 | PUT /room-preferences/default | expected preference_version；返回 202 后等 Saga，切换中不宣告监控切换完成 | Room/Monitoring，T3 |
| 异步进度、刷新恢复 | GET /operations/{id} | 摘要定位本人操作，unknown 只回查，不新建同目标操作；白名单域分派 | Gateway/Identity/Room/Payment，T2 起 |
| 查看余额、手动刷新 | GET /room-bindings/{id}/balance，POST /room-bindings/{id}/balance-refresh | amount/fetched_at/source/stale；刷新 202/冷却，不添加采集明细 | Room，T4 |
| 7/30/90 天、日历月份/方向键/Esc、应用范围/粒度 | GET /room-bindings/{id}/consumption，GET /room-bindings/{id}/monitor-samples | calendar draft/apply 属本地；同一上海范围；null 与零区分、已知合计，图表不反推余额 | Room/Monitoring，T4 |
| 同步学校历史 | POST /room-bindings/{id}/history-sync | 幂等 202；分段窗口和 coverage/sync_status，查询操作结果 | Room，T4 |
| 采集明细上一/下一页、重新加载 | GET /room-bindings/{id}/monitor-samples | 实际样本集合与稳定 total；410 重载第一页，首条余额差/无读数 null，重复日读数不累加 | Monitoring，T4 |
| 监控设置草稿/保存/关闭 | GET /monitor，PATCH /monitor | monitor.version/generation；60..1440、次数 1..5 含首次；关闭只提交开关与版本，保留历史 | Monitoring，T3 控制、T4 运行、T5 提醒 |
| 立即采集、取消本次 | POST /monitor/runs，GET /monitor/runs/{id}，POST /monitor/runs/{id}/cancel | run.version；取消不关闭后续计划，cancel_pending/in_flight_count，不伪装瞬时消失 | Monitoring，T4 |
| 邮件异常/采集健康 | GET /monitor | control/health/notification 分开，失败/未知/在途/重试事实来自服务端 | Monitoring/Notification，T4/T5 |
| 打开缴费、快捷金额、确认建单 | GET /payments/capabilities，POST /payment-orders | 金额 min/max/step 来自能力；disabled 不建单，固定目标/金额和原幂等键 | Payment/Adapter，T6 |
| 订单恢复/状态、二维码获取/刷新 | GET /payment-orders/{id}，GET /payment-orders/{id}/qr，POST /payment-orders/{id}/qr-refresh | 未解决引用恢复原订单；图片/202/错误分支，未知 expires_at 不造倒计时；不二次建单 | Payment/Adapter，T6 |
| 关闭弹窗、切页、收起导航 | 本地界面操作，返回时 GET 原操作/订单 | 不代表取消后台业务；普通 AbortController 不等于 cancel-run | 前端，T1 起 |

## 路由、组件与状态边界

| 落点 | 职责与完成条件 | 阶段 |
| --- | --- | --- |
| frontend/src/app | /login、/overview、/details、/rooms、/monitor；Router/Query/会话初始化/守卫，刷新可恢复，四主导航 | T1/F1，当前只建立入口 |
| features/auth、components/layout | Login/Agreement/AccountMenu；AppShell 手机与桌面账户入口，密码/CSRF 内存状态，退出确认后清缓存 | T2/T3 |
| features/rooms、hooks/useOperation | 本人列表/候选/默认，幂等意图和持久进度，不把 viewing 当 default | T1 操作控制器、T2/T3 功能 |
| features/overview、features/history | 独立组件状态、日期范围、消费/样本；来源、覆盖率和快照明确 | T4 |
| features/monitoring | saved/draft 分离、冲突保留草稿、版本分清、关闭不校验其他草稿 | T3/T4/T5 |
| features/payments | 能力/订单/QR，冻结寝室金额，恢复引用和 unknown 可操作 | T6 |
| components/feedback、Modal/ConfirmDialog | loading/empty/error/stale/operation，键盘焦点、长错误、在途边界始终可见 | T1 起，T7 回归 |
| Chart/Trend/DateRangePicker、lib/money/dates | 图表必传数据、null 断点、更新不重建、卸载释放；十进制与上海日期工具 | T1 基础、T4 功能 |
| api/generated.d.ts、mocks、tests | 契约生成与 CI 检查，10 个显式合成场景，生产无 mock 注册 | T0 场景，T1 客户端/隔离入口 |

服务端事实在按 user_id 隔离的 Query 内存缓存；当前查看房间、已应用范围/粒度/页码在经验证的 route query；密码、验证码、CSRF、草稿在内存；snapshot 按用户/绑定/范围隔离；最小恢复 ID/幂等键可在按用户隔离的 sessionStorage，恢复前再查本人对象。退出时取消请求、清缓存/恢复信息/QR URL。

当前范围不含管理端、学校解绑、退款、自动扣款、多学校或节点级高可用。所有原始学校不确定项已进入 [待确认清单](acceptance/school/待确认事项.md)；真实支付/邮件未验收，不作为已开放能力。

T3 新增 GET /room-bindings/{id} 支持独立查看本人缓存和 URL 刷新恢复；404 清理对象缓存并返回本人列表，不修改默认或监控目标。
