# 搜索焦点与采集明细更新

日期：2026-10-05（Asia/Shanghai）。版本：0.18.3开发分支增量。

## 修复范围

- 寝室搜索的粗边框改由整个搜索框呈现，包含左侧图标；鼠标和键盘均保留可见焦点，失焦恢复原样。
- 采集列表的total来自所选日期范围的固定快照，没有50条上限。第一页此前没有定时更新，普通重新查询也继续沿用旧token。
- 第一页可见时每60秒不带token读取最新集合，隐藏暂停，返回时更新过期查询。后续页保留同一快照，分页缓存加入token避免新旧集合混用；主动刷新回到第一页。
- 本次只读取应用采集记录，不触发学校同步或额外采集；后端接口与持久采集逻辑未修改。
