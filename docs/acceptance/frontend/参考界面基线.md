参考 1100px 断点缩窄侧栏与卡片，760px 下改横向导航/单列；768px 仍保留侧栏。浅蓝主题的圆角、描边、图表和卡片信息层级作为视觉基线。正式工程采用独立样式变量，不直接复制通用隐藏选择器。

375px 的参考页面隐藏 sidebar-bottom，账户退出不可达；监控的字段提示/说明也被浅蓝通用 CSS 隐藏。正式 AppShell 的手机账户入口和状态块在 F1/F2/F5 实现，表单错误、unknown/过期和后台说明始终可见。参考的随机验证码、本地默认切换、固定日期、余额反推历史及演示缴费均由后端事实替换。

组件与路由职责见 [需求追踪](../../T0需求追踪表.md)。本轮只有正式入口可构建，业务界面尚未实现；参考截图不作为真实业务、手机无障碍或部署验收结果。
