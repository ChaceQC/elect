# T1 前端公共层验收

日期：2026-10-01；版本：0.2.0；范围：F1，学校登录/查询与异步业务联调在 T2–T6。

## 已验证

- Router/Query/会话 Provider、四页 AppShell、初始化守卫、直达/刷新/前进后退与桌面/手机账户入口。
- 同源 Cookie、内存 CSRF、request_id、204/202/401/429/503、超时与 AbortSignal；应用过期与学校认证异常区分。
- 会话切换先隐藏旧数据、取消请求/清 Query 缓存与旧恢复信息；迟到响应不能写入下一会话。
- 用户/对象/范围/分页/快照查询键，安全 GET 有限分类重试、遵守 Retry-After，写操作不自动重试。
- 同一逻辑操作的请求和幂等键冻结；网络失败恢复原请求，202 仅保存受理标识；operation/run/order 独立查询，unknown 非终态。
- 隐藏暂停与 2/5/10 秒轮询、两分钟后手动查询；只从服务端摘要恢复既有对象，不根据 poll_url 请求外站。
- 版本冲突/响应丢失先读取当前状态，保留草稿，显式查看后才能再提交。
- Modal 焦点循环、Escape/焦点返回，持久 StatusBlock/Error、轻量 Toast、金额/null/上海日期工具；生产无 MSW/场景数据。

## 实际结果

- contract:check、lint、typecheck、build 通过，Vitest 15 passed。
- Playwright 3 passed：1440/375 宽度的路由、导航、账户、反向 Tab/Escape/焦点恢复与无横向溢出；业务关闭时持久提示。
- `sh deploy/check.sh` 在 Docker 中重复上述验证并执行后端规则/契约检查；测试只挂载 docs 和合成场景，生产镜像无跨工程构建输入。
- 全新 Compose 的生产 Nginx/Gateway/前端实际 HTTPS 检查：/details 回退并由守卫进入 /login，FEATURE_DISABLED 正确，跨站写请求 ORIGIN_REJECTED，无注册 service worker。
