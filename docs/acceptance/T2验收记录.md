# T2 登录与本人寝室读取验收

日期：2026-10-01（Asia/Shanghai）；版本：0.3.0。T2-01..04、P2、P3a 与 F2 登录/重认证、F3 只读范围交付；撤回、默认初始化与绑定写入留在 T3。

## 实现范围

- 正式 httpx A01–A04/B01、学校 RSA、图片校验、逐跳白名单/固定公网连接、分阶段超时/总预算；Redis 原子验证码、nonce 归属、跨副本单飞、五并发/后台四资源与 429 共享冷却。
- AES-256-GCM/独立 DEK/KEK/AAD、HMAC 多版本别名、验证后暂存/激活与持久登录恢复；未保存/激活不签会话，失败密码不覆盖旧凭据。
- 安全应用 Cookie、实时 introspection、CSRF/Origin、协议记录、明确后台授权、学校认证修复与普通退出；学校失效保留应用会话，后台恢复只用本人已授权密文，OCR 最多两次取图/一次提交。
- B02 镜像/精确余额、持久同步/租约接管、本人操作 404、分页搜索、B03 候选脱敏/加密缓存、empty/failed/stale/loading/复核状态；无默认偏好时保留 null。
- 登录页真实验证码、协议阅读/版本重置、授权不预勾、重复提交保护/密码清理；账户桌面/手机可用，退出失败不宣称注销。候选防抖/至少一秒间隔/取消与乱序/过期处理。
- 内部认证 TLS/私有 CA/独立 Secret、T1 Secret 保留升级、三域迁移与 22 个长期进程。独立生产构建不依赖 example。
