## 验证

`scripts.t3_control_smoke` 在显式一次性环境使用真实 MySQL/Redis、ASGI 服务签名链与合成学校登录；没有调用真实学校，没有启动真实采集或邮件。覆盖：

| 场景 | 检查 |
| --- | --- |
| 关闭/取消/切换/撤权/租约过期 | 迟到执行尝试实际 INSERT sample，被屏障拒绝，样本数仍为 0 |
| 有效执行与关闭并发 | 有效结果先持锁提交时保留已成功样本，关闭随后生效；不删除历史 |
| 版本/参数/权限 | 未登录 401、CSRF 403、缺版本 428、非法间隔 422、同版本并发保存仅一个 200，另一个 409 |
| 幂等与恢复数据 | 首次并发 prepare 相同结果，重复 commit 不改代；不同目标/终态冲突拒绝 |
| 默认切换 | Gateway 发起入口仍关闭；内部服务真实回查 Room 操作，未提交不得完成；关闭意图经 commit 保留 |
| 补偿 | 未明确结束不得补偿；新代次恢复旧目标，旧执行不能提交，补偿终态不能被 commit 覆盖 |
| 凭据更新本域原语 | prepare 后待认证仍可保存参数；版本确认后恢复当前意图，旧执行仍失效 |
| 事务失败 | 注入 Outbox 错误后，配置/代次/运行取消一起回滚 |
| 提醒取消边界 | 关闭/阈值/间隔变更取消 reserved，保留 authorized/sent；在途数量及 sending 状态如实显示，仅改间隔保留已发送计数 |
| 邮箱 | 数据库存密文；错误 owner/version、篡改被拒绝，多版本密钥可读旧值 |
| 升级 | 新迁移/Secret 的重复执行；现有连接凭据和服务签名密钥保留 |
