# 真实学校验收记录模板

- 上海执行日期：
- 代码/镜像版本、契约版本：
- 执行人/输入类别（不记录原账号、密码、寝室 ID、token）：
- 已明确授权的接口、目标类别、金额/邮箱范围：
- 学校 API 编号及前置状态：
- 预期结果/错误或故障注入：
- 实际结果、操作/订单/运行的应用 ID：
- dispatch 次数、回查方式、终态证据或 unknown：
- 脱敏结构/截图位置：
- 验收结论、能力是否继续关闭、具体下一步：

保留学校成功/失败原始枚举的脱敏结构，不保存实际账号、支付票据、原始 URL、Cookie、密钥或完整响应。模拟测试与真实检查分别注明来源；QRCode 获取、SMTP 接受分别不代表付款到账/最终邮箱送达。
