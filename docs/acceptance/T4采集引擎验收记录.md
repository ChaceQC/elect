# T4 持久采集引擎增量

日期：2026-10-01；版本：0.8.0；范围：P5b 与采集明细后端；前端和阶段故障回归继续接入。

## 交付

- 独立 Scheduler（5秒/最多100计划）、Worker、恢复器（15秒），使用 MySQL UTC 时间、SKIP LOCKED、锚点最新逻辑槽、唯一 run/sample 与既有提交栅栏。
- 45秒短租约、10秒续租、90秒 attempt；最多3次尝试，后续30秒/2分钟加抖动并尊重 Retry-After。学校访问在事务之外执行，断连/关闭/取消/切换后不能提交旧结果。
- monitor.run_ready Outbox/持久签名队列/事务 Inbox/领取后 ACK，恢复使用新 event_id；MQ不可用仍扫描MySQL。Room历史唤醒同样为提示，窗口事实仍在本域数据库。
- 运行创建/查询/版本取消、固定成员30分钟快照、真实余额差/首条null、balance_only质量与学校日读数来源字段；关闭后仍可读取本人历史。
- Adapter按本人目标的学校roomId精确取B02余额，并以独立受限命令更新该Binding缓存；不允许监控服务自行发送任意余额观察。
- 内部 `/monitor/metrics` 提供调度延迟、到期任务/租约、运行/尝试分布与Outbox积压；不含账号或学校数据。
- monitoring_0004新增采集时的间隔，配置变化不改变历史gap判断。已有Secret重复upgrade_controls并重建RabbitMQ/应用后再迁移，保留原连接凭据与卷。
