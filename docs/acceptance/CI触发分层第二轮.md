## 范围与门禁

- 非main分支push保留后端规则、单元、契约、迁移清单、查询配额数据库，以及前端规则、类型、单元、构建、浏览器全部快速检查。
- PR与版本标签保留第一轮三组完整覆盖与镜像复用；Secret、卷、会话不跨作业，生产start/upgrade和业务源码未修改。
- 7项CI定向检查通过，覆盖事件/默认手动范围、快速及完整结果集合的失败/取消/跳过/缺失拒绝，保留镜像来源/标记/ID/损坏拒绝路径；actionlint和git diff --check通过。
- main push按用户要求整体排除，合并后不再重复CI；main仍禁止直接推送，合并前必须满足最新PR完整检查及严格分支保护。
- 本轮不合并main、不发标签、不升级现有部署；未读取真实凭据或调用学校/SMTP/支付。
