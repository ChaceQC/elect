## 真实链路

[分类结果](school/T5-live-delivery.json)：在独立 MySQL/Redis 容器和正式业务代码的内部 ASGI 联调中，完成真实学校登录、本人绑定/默认读取、真实 B02 新鲜采集、低余额事件、Notification 持久 job、发送许可、真实 SMTP 和 Monitoring 结果镜像。验收临时将阈值设为实际余额加 5.00 元、总次数 1；未伪造余额，不代表真实寝室自然跌破日常阈值。

SMTP 一次尝试后明确接受，job/Monitoring 均为 sent；用户于 2026-10-02 确认测试邮箱已收到。只向 email_auth.txt 指定的唯一收件人发送一封。测试监控恢复原设置并关闭、应用退出；未执行学校绑定写或支付。

[此前连接失败](school/T5-live-before-tunnel.json)发生在正文发送前。诊断确认本机 Clash TUN 将 SMTP 按 Match 导向代理，连接被重置；物理网卡直连 TLS 成功。验收使用仅一个 SMTP 目标、随机认证、仅一条连接的临时 HTTP CONNECT 通道，绑定 Docker 私有网桥与物理网卡，TLS 验证保持开启。测试结束自动关闭通道，未改系统全局代理。正式部署可选 SMTP Secret 中的 proxy_url，不能假定环境 HTTP_PROXY 会自动作用于 SMTP。
