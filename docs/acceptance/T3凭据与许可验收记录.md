## 定向验证

`scripts.t3_credential_smoke` 仅在显式一次性环境执行；实际 MySQL/Redis、ASGI 服务身份链及合成学校，未读取 auth.txt 或执行真实学校/邮件/支付写入。

| 场景 | 结果 |
| --- | --- |
| 屏障服务不可用 | 保留 Adapter 原凭据，操作 reconciling，不能提前完成撤回 |
| Adapter 删除后响应丢失 | 密文/DEK/学校身份/历史暂存已清空，重复续作成功，唯一撤回台账 |
| 应用会话与恢复 | 会话保留，me 给出 revoking/操作摘要；完成后 revoked，账号展示可读 |
| 旧执行、旧登录、旧撤回 | 旧执行不能写样本；旧登录不能恢复授权；旧撤回重放不删除随后新版本 |
| 激活三阶段响应丢失 | prepare-update、activate、commit-update 均可从持久记录恢复，期间并发撤回拒绝 |
| 暂存过期 | 未激活更新补偿旧凭据，释放用户槽；旧运行仍被新代次拒绝 |
| 迟到 Redis 写入 | 真实后台认证暂停在 token 写入处，完成撤回后放行；迟到 token 删除、结果拒绝 |
| 迟到人工认证 | 人工认证在撤回前开始、学校响应在撤回后返回；旧认证不能创建新暂存或激活 |
| 发送许可 | 并发同 job/epoch 返回同许可；过期/不同 epoch 不重授；取消前在途保留、取消后拒绝 |
| 许可输入与竞态 | 代次/邮箱/凭据/样本新鲜度/冷却/序号不符拒绝，并发关闭和授权串行 |

上述检查均已在隔离环境通过；补充撤回缺版本 428、错误 CSRF 403、旧版本 409、匿名操作查询 401、跨用户操作查询 404。最终合成凭据操作槽与可访问学校的同步任务全部终结，才恢复真实 Worker。

## 验收边界

本批验证使用合成学校，不能作为新的真实学校联调或真实 SMTP 验收。默认切换/绑定台账、F3/F5 控制界面继续按 T3 推进；Scheduler/采集/运行恢复为 T4，实际邮件为 T5，支付为 T6。真实 batchAdd 没有指定目标，开关保持关闭。
