# 前端开发与部署

日期：2026-10-02；当前版本：0.12.0；API契约：0.12.0，34个公开接口。

frontend独立使用React/Vite/JSX、Node22.23.2/npm10.9.8及package-lock。生产构建只读frontend，运行镜像仅含dist/Nginx，不导入example或注册MSW。所有API使用同源/api/v1，公开配置不含学校/SMTP/服务密钥；个人请求、二维码、验证码no-store，CSRF只在内存。

```sh
sh deploy/check.sh
sh deploy/test-stack.sh /absolute/new-directory elect-test-t7
sh deploy/test-t7-recovery.sh /absolute/new-directory elect-test-t7
ELECT_TEST_IMAGE=elect-backend-smoke:ops sh deploy/test-t7-browser.sh /absolute/new-directory elect-test-t7
```

check在Docker内完成锁定依赖、lint/typecheck/契约/单元/build和Playwright。Playwright基于生产build/preview；全栈浏览器另对接Nginx/Gateway/实际SQL与内部TLS，提前登录使用合成学校，浏览器不拦截API响应。测试目录/项目必须独立，不以测试fixture初始化生产。

学校登录/寝室/查询/监控/提醒具有分阶段真实证据；写入/真实SMTP开关默认关闭。支付支持本地取消/原订单恢复，1元实际付款与B02增加1.00元已记录，但D02业务500导致自动终态映射仍未验收。二维码不代表已支付，取消不退款或保证学校旧码失效。

375/390/768/1280/1440px、长错误、键盘弹窗焦点、日期错误关联、可读图表数据、触控44px与缩放等效视口已回归。跨标签页登录/退出清理会话、缓存和草稿；隐藏页面暂停轮询/日期时钟，图表观察器和Object URL及时释放。只验证了Chromium；Firefox/Safari与原生日历平台差异、人工屏幕阅读器及真实浏览器200%缩放保持待验。

ECharts按需加载Line/Aria/Grid/Tooltip/Canvas模块，并提供文字数据替代，图表动画关闭。主页面共用基础组件；当前构建包体与实际范围见T7验收。部署域名由Compose配置，与可信Origin一致，不重编译JS；本轮按用户要求跳过生产证书/域名更换演练，保留既有测试HTTPS和安全Cookie。
