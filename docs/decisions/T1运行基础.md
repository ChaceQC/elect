# T1 运行基础

日期：2026-10-01。完整部署结果由 T1 验收记录确认。

## 服务身份

每服务独立 Ed25519 密钥，运行 Secret 只持有该服务私钥和公开 trust bundle。JWT 使用 PyJWT 的 EdDSA 实现，TTL 60 秒；接收方强制检查算法、kid、iss/sub、单一 aud、iat/exp、UUID jti/request_id、命令 scope 和 trust bundle 的接收服务/权限白名单。jti 是请求唯一标识，业务去重使用领域幂等台账或 Inbox，不用短期 token 代替持久去重。

用户上下文包含签名的 user_id 与正整数 session_version；任何 X-User-Id 均不参与身份构建。领域路由还须调用对象归属校验，失败统一 404。Gateway 从 Identity 实时校验应用会话后的传播在 T2 接入，当前不签发应用会话。

`GET /internal/v1/context` 是基础设施诊断入口，需要 `foundation:read` 权限，只返回已验证的服务、用户、会话版本与关联 ID。服务身份失败返回内部错误 `401 SERVICE_AUTH_REJECTED`，不改变公开 28 个 API 契约。该诊断入口不开放公网代理。新增业务内部命令在各阶段登记独立 scope，并同步 trust bundle。

浏览器写请求使用统一 HTTPS Origin 与已验证会话的 CSRF token。T1 关闭的业务写入口先校验 Origin；真实会话写请求的 CSRF 集成留待 T2。所有公开业务入口目前返回 FEATURE_DISABLED，不产生模拟登录或业务事实。

## 配置与日志

`ELECT_RUNTIME_FILE` 指向本服务只读 JSON Secret，字段为 schema_version、service、db_url（Gateway 无此字段）、redis_url、amqp_url、signing_key、key_id、trust_bundle；URL 和私钥使用 SecretStr，配置错误仅输出分类说明。可信 Origin 只读取公开 ELECT_PUBLIC_ORIGIN，副作用开关严格使用 true/false 并默认关闭。

本域运行连接只允许本库 app 账号，连接池 2 条基础连接、3 条溢出，连接时设置 UTC。运行 ready 检查实际 Alembic revision；live 不检查外部学校。后续数据库修订通过迁移脚本读取最新 head，同步 readiness，不能把学校宕机变成全站不可用。

框架访问日志关闭，JSON 日志仅记录 event/service/request_id/status/duration_ms/count/error_code；原始 SQL、URL 查询串、请求体和异常正文不写入日志。Nginx 使用同样的脱敏约定。审计只接受登记 DTO 字段，不能用自由文本记录上游响应。
