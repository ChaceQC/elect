# T2 认证与只读实施决策

日期：2026-10-01。本阶段不开放默认初始化、学校绑定写、支付或真实邮件。

## 认证与恢复

人工登录使用正式 httpx A01–A04/B01，保留学校小端 RSA。CAS JSON 兼容实际 `text/plain` 容器，仍严格校验 JSON/图片 MIME、文件头与大小。响应只解压一次并限制解压后体积；A03 不跟随跳转、不自动重复。验证码/认证/读取总预算分别为 30/60/25 秒，connect 3 秒、pool 2 秒，等待共享资源计入总预算。

学校跳转逐跳校验固定 HTTPS 域名和公网 IP，最多六跳；连接固定到校验过的 IP，保留 Host/TLS SNI，各主机独立连接池。系统 DNS 返回透明代理的 `198.18.0.0/15` 映射时，通过固定 `https://dns.google/resolve` 查询学校域名，校验结果后连接真实公网 IP，不直接放行虚拟网段/内网。解析缓存最多 60 秒。

Redis 加密 challenge 绑定安全浏览器 nonce，刷新先原子作废旧图、迟到者不能发布、消费仅一次；故障返回 503，不回退进程字典。共享账号 HMAC 单飞与五请求租约限制跨副本并发，后台最多占四个资源，为人工认证保留一个；学校 429 共享冷却，安全 GET 在同一总预算内最多两次。学校认证成功后用多版本 HMAC `account_reservations` 占位同一 credential_ref；暂存 AAD 使用 attempt_id，激活时以最终 owner/version 重新加密。密码与学号同一 AES-256-GCM 负载，独立 DEK/KEK 包装，token 仅在 Redis 加密缓存。

Identity attempt 以 nonce/challenge 的 hash 唯一定位，密码只在内存参与独立密钥 HMAC 摘要；协议元数据与各阶段持久保存。MySQL GET_LOCK 串行推进同一 attempt，恢复器仅查询/激活已验证暂存，不保存或重提密码。确认 activated 后，浏览器请求才能签发会话；丢失响应的重试只轮换该 attempt 会话。失败尝试不覆盖旧凭据。

应用 Cookie 为 256 位随机 token，DB 保存 HMAC；闲置 12 小时、绝对 7 天。CSRF 由独立 pepper 派生并保存校验 hash；每个受保护请求实时 introspection。学校失效保留应用会话，logout 只吊销当前会话。已有会话的重认证校验 CSRF，其他学校账号返回 REAUTH_ACCOUNT_MISMATCH。

学校 token 缓存最多 15 分钟并按 credential/version 分区，使用和提交前核对当前版本/状态。未授权不自动重提密码；已授权后台恢复单飞，OCR 最多两次取图、一次有效 A03 提交，失败进入 requires_reauth 并保存审计/广播。人工页面不运行 OCR。凭据事件由两个持久订阅队列保留，T3 接入监控消费与屏障前不创建监控。

## 内部安全与部署

Gateway 新增 identity:browser/session:introspect/captcha:create/room:browser，Identity 新增 credential:authenticate/credential:activate/credential:read，Room 新增 school:rooms 独立命令权限。JWT 校验服务、scope、用户上下文，任意 X-User-Id 无效；对象再次校验本人归属。

Identity/Adapter 使用独立内部服务器证书与私有 CA，密码/不透明会话经验证服务器证书的 TLS 传输。首次 provision 增加 KEK、lookup HMAC、Identity pepper、内部 CA/证书；已有目录仍拒绝覆盖。CA 私钥不挂载到运行容器；服务器证书 90 天、CA 365 天，须在到期前维护。仅 Adapter 接入 school_egress，延迟 OCR 推理的内存上限为 1024 MiB。

MySQL 运行事务改为 READ COMMITTED；明确行锁与唯一约束继续保护版本/幂等。默认 REPEATABLE READ 在并发首次登录的不存在键上产生 gap lock 冲突，调整后两账号并发通过。事务仍只访问本域，不跨库读写。

## 只读寝室

同步接口持久返回 202，Room Worker 扫描 MySQL 并领取 120 秒租约，重启接管到期任务，提交核对领取者/租约。成功更新镜像与余额；失败保留 stale，首次失败为 failed、首次成功空列表为 empty。已有关系缺失先 rechecking，保留历史和默认；移除屏障与默认初始化由 T3 交付。

B03 每次仅请求一页，传学校页面搜索/分页参数，筛选精度仍返回 unverified。精简候选不含住户资料，完整原记录在 Adapter 加密缓存，绑定本人、查询会话与五分钟期限。公共 total 来自学校，不能前端过滤后伪造。
