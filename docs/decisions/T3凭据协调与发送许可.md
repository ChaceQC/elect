# T3 第二批：凭据协调与发送许可

日期：2026-10-01（Asia/Shanghai）。版本 0.4.0；本批完成 P5a-04/05 和 F2-06，T3 的 Room 绑定/默认及监控设置界面继续实施。

## 激活与撤回

Identity `users.credential_operation_id` 是每用户的持久操作槽。学校验证成功后，LoginSaga 在用户事务中占槽并记录候选凭据版本；并发登录或撤回不能越过槽位。激活协调从登录编排拆到 CredentialActivation：Monitoring prepare-update → Adapter activate → Monitoring 回查 Adapter 并 commit-update → Identity 确认版本、释放槽，随后才签发应用会话。

prepare 使旧运行和未授权提醒失效；更新保留监控启用意图，撤回则关闭意图。Adapter 激活/撤销必须自行查询 Monitoring 持久屏障，不能只相信调用者。每步按 attempt/operation 幂等；网络失败由已有 Identity 恢复进程继续。已占用户槽的登录不因浏览器尝试 TTL 到期而遗弃协调；最终学校暂存过期且尚未激活时，回查旧版本、补偿监控、释放槽并将尝试置 failed。补偿也使用新代次，旧执行不能复活。

`DELETE /api/v1/auth/school-credential` 使用 credential_version，缺版本 428、版本冲突或另一凭据操作进行中 409。Identity 本域事务保存 credential_operations、占槽、撤销 consent 与审计后返回 `202 + operation_id`。重复撤回同一用户/旧版本返回原操作，不能撤回后来的新版本；普通应用会话继续有效。

恢复顺序为 Monitoring prepare-revoke → Adapter revoke → Monitoring commit-revoke → Identity succeeded。每一步重复确认安全；屏障服务不可用时不先删除凭据。Adapter 在同一事务设置 revoked/use_allowed=false，清空密码/学校身份密文、DEK 和该凭据的全部 staged/activated 密码暂存，再清理已失效暂存 token 与旧版本 token。Redis 清理失败时操作保持 reconciling，重复清理后才报告完成。单独 AES-GCM 保存账号展示值，用于撤回后的账户识别，不保留密码。

人工激活和后台重认证写 token 前后都复核 Adapter 的持久版本/状态。撤回若发生在检查与 Redis 写入之间，迟到写入被清除并返回 SCHOOL_REAUTH_REQUIRED；缓存不能恢复持久授权。旧登录尝试在凭据版本改变或撤回后不能重新签发会话。

人工认证在调用学校前观察持久凭据版本和 revoked_at，收到学校响应后在暂存事务中锁定凭据行并复核。撤回或另一激活发生在等待学校响应期间时拒绝旧认证；尚未创建暂存的在途请求也不能重新授权。网络请求期间不持有数据库事务锁。

## 发送许可

唯一内部入口为 Notification → Monitoring `/alert-slots/authorize-send`，权限 `monitor:authorize-send`，用户上下文必须匹配 owner。锁顺序沿用 monitor → episode/slot，关闭/取消和取得许可的线性化点均在本域 MySQL 短事务中。

授权检查 active/enabled、凭据允许且无屏障、当前 open episode/目标/代次、slot 代次/邮箱版本/序号、当前最后成功样本和低余额条件。样本必须来自当前凭据/目标/运行代次、非未来且在数据库时间前 5 分钟内；过期样本禁止新授权。每用户冷却沿用当前 interval，并将最近许可时间纳入判断；其他 authorized 在途 slot 存在时不授新许可。

send_permits 持久保存 permit_id、alert_slot_id、job_id、execution_epoch、expires_at。许可有效期 30 秒，同 job/epoch 重放返回相同有效许可；不同 epoch 或过期不把已 authorized slot 再次授权。关闭前已取得许可的在途邮件可能完成，关闭后不授新许可，摘要保留真实 in_flight_count/cancel_pending。

本批没有 Notification job/SMTP、发送失败回报或投递恢复器。P6 必须在本协议上实现明确未发出的重试、每次重新取许可以及 delivery_unknown 占额；不能仅因许可过期就假定未发送并盲重发。
