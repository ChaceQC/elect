## 数据库与 Secret

七个数据库为 elect_identity、elect_school、elect_room、elect_monitoring、elect_notification、elect_payment、elect_audit。每库有独立 app 与 ddl 账号、独立 Alembic 初始 revision 和 alembic_version；Gateway 没有业务库账号。不跨库外键/SELECT、不共享领域 ORM。运行账号只得本库 SELECT/INSERT/UPDATE/DELETE；DDL 账号还得 CREATE/ALTER/DROP/INDEX/REFERENCES，只挂载到迁移作业，root 仅初始化使用。

[Secret 清单](../../deploy/secrets.example.yaml)明确每种密钥的接收服务。普通 `.env` 只有公开配置和文件路径；数据库 URL、JWT 私钥、SMTP/MQ/Redis 凭据和加密密钥均通过只读文件注入。School KEK/HMAC 只有 Adapter 持有；邮箱与支付密文使用所属域独立密钥，密文信封包含算法、nonce、包装 DEK 和 key_version，不共享学校解密权限。

内部服务身份使用每服务独立 Ed25519 签名密钥与公开 trust bundle，JWT 初始 TTL 60 秒，验证 iss/sub/aud/iat/exp/jti、算法与命令权限；Gateway 的用户上下文只对当前内部请求有效。Worker 使用所属域受限身份，不使用全服务通用密钥或可伪造 X-User-Id。实现与权限故障测试在 T1。

ELECT_DOMAIN 是单个小写 DNS 名称，不含协议/端口/路径；统一派生 https Origin。TLS 路径为绝对路径，证书经只读 Secret 注入；SAN、有效期、公私钥匹配由 T1 tls-check 检查。模板仅替换 ELECT_DOMAIN，保留 Nginx 变量。
