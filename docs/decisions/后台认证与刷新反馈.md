# 后台认证与刷新反馈

日期：2026-10-05（Asia/Shanghai），版本0.18.3，按用户追加要求实现。

## 后台自动认证

每轮background_auth最多获取5张验证码、最多提交2次A03登录。OCR无法解析时继续取图，消耗同一个5张预算；识别成功才提交。首次SCHOOL_LOGIN_REJECTED后重新建立学校验证码会话，再在剩余预算内尝试；第二次拒绝立即停止。成功立即结束，不用满次数。

网络超时、服务不可用、协议异常和OCR运行异常不自动重放登录。仍受原整体deadline、单账号锁、每账号5分钟最多2轮后台登录及同进程OCR串行限制；最多5张不承诺在超时前一定取得5张。用尽或明确拒绝后沿原逻辑进入人工重新认证，人工登录验证码流程不变。

代码将循环独立到School Adapter的application/background_auth.py，SchoolSessions保留凭据许可、缓存、账号锁和失效处理，真实凭据不进入日志或测试。

## 刷新反馈

共享QueryAction覆盖总览/余额/历史刷新：处理中旋转原RefreshCw图标，按钮保持原标签；紧凑按钮始终只显示图标，使用原名称供屏幕阅读器和悬停提示。去掉“查询已受理，等待结果”“正在从学校读取”“查询已完成”及重复的“本次同步范围”行。

绑定同步与采集明细刷新同样使用旋转图标，处理中禁止重复提交。查询错误、未知结果、取消及轮询暂停恢复仍可见；不会用动画掩盖异常。aria-busy和屏幕阅读器状态提供非视觉反馈；prefers-reduced-motion关闭持续旋转。布局、主题及日期选择器保持原参考。
