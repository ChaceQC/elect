# T3 第一批：监控控制基础

日期：2026-10-01（Asia/Shanghai）。交付 P5a-01/02/03 的控制事务及 P5a-04 的本域原语；T3 整体尚未完成。

## 当前可调用范围

Gateway 已接通 `GET/PATCH /api/v1/monitor`，实时检查应用会话；写入检查 Origin/CSRF。首次读取或内部 prepare 幂等创建 disabled monitor，默认间隔 60 分钟、总提醒次数 1、阈值 20.00、邮箱 null；未绑定/未授权不能开启。配置默认值不产生学校业务数据。

保存使用 monitor.version，缺失返回 428，冲突 409 包含 current_version；字段省略保留、无变化且版本匹配不改代。响应丢失后先 GET 对账，旧版本不会覆盖其他标签页。分钟整数 60..1440、次数 1..5、阈值 >0 且 <=10000.00，email=null 仅在关闭时允许。邮箱仅校验格式，不宣称归属验证。

配置、generation、运行 epoch/取消、旧代次待发送 slot 失效与审计 Outbox 同事务；RabbitMQ、Redis、学校或 SMTP 均不参与控制领域事务。Gateway 的应用会话验证仍依赖 Identity/MySQL。等待凭据修复时允许保存参数，保持 requires_reauth；不因保存参数恢复执行。切换中仅允许关闭意图或无变化保存。

邮箱由独立 `monitoring_encryption_key_bundle` 中的 AES-256-GCM 密钥加密，AAD 包含用户和 email_version；不借用学校密码密钥。密钥仅挂载 Monitoring API；旧版本密钥需随备份受控保留。

## 取消与提交屏障

写操作统一按 monitor → run → episode/slot 加锁。`fenced_transaction` 使用数据库 UTC 时间核对 active/desired_enabled、active_run_id、generation、binding、credential_version、授权屏障、execution_epoch、租约持有者与有效期。校验和调用者的样本提交使用同一个事务，禁止校验后释放锁再另开事务提交。

关闭/改代取消 pending/retry_wait，running 置 cancel_requested 并提升 epoch。单次取消只修改目标 run，不关闭 monitor 或改变后续时间槽；成功样本保留，同时取消该样本尚未授权的提醒。已授权 slot 保留在途事实，不能假装外部邮件瞬间撤销。监控摘要按实际运行租约与授权记录返回 in_flight_count/cancel_pending。

本批只有控制和提交校验原语。Scheduler、领取/续租、采样提交实现、过期租约恢复及公开 run 查询/取消按 T4 接入；本批验收的 run/sample/slot 为显式隔离测试构造。

## 默认切换协议

prepare 按 operation_id 与请求摘要去重，记录旧 binding、目标、原 preference_version。重复相同请求不改代；同编号不同请求、并行控制操作或旧偏好版本返回 409。prepare 使旧运行与未授权提醒失效并进入 retargeting。

commit/compensate 通过受服务 JWT 保护的 Room `/controls/preference` 回查持久 switch_default 操作，调用方不能直接提供证明。Room 仅在 `preference_committed/monitor_committed/completed`、已有 committed_preference_version 且实际偏好目标/版本一致时确认提交；只有未提交且已进入 failed/cancelled 的 `compensating/compensated` 操作允许补偿。这些 saga_step 值约束下一批 Room 协调器实现。Monitoring 已完成的操作重放只核对原目标/版本，后续其他偏好变更不会覆盖原结果。

commit 必须匹配目标与原版本+1；以最新 desired_enabled 恢复，保留切换中关闭意图。补偿恢复原目标并使用新 generation，不复活旧任务；已 committed/compensated 操作不可互相覆盖。首次无 monitor 的 prepare/commit 最终仍为 disabled。

## 凭据协调边界

`CredentialControls` 已提供凭据变更/撤回的 prepare/commit 本域原语；prepare 持久阻断旧执行，撤回同时关闭意图，更新则保留意图。commit 需调用方从 Adapter 获得当前版本/状态证明，只能恢复最新版本。当前公开撤回入口仍关闭，Identity 登录尚未调用这些原语，也未消费凭据事件；本批不宣称凭据撤回端到端完成。
